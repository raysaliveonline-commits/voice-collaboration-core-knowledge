# Voice and collaboration glossary

| Term | Meaning |
|---|---|
| ACK | SIP request acknowledging a final 2xx response to INVITE or participating in other transaction/dialog behavior as defined by SIP. It does not prove media is flowing. |
| B2BUA | Back-to-back user agent; terminates one SIP dialog and creates another. |
| CUBE | Cisco Unified Border Element, a session border controller function on supported Cisco platforms. |
| Call-ID | SIP identifier used to correlate messages in a call/dialog context; SBC legs may have different Call-IDs. |
| CSeq | SIP sequence number and method used for request sequencing. |
| CUCM | Cisco Unified Communications Manager. |
| DSP | Digital signal processor, used for media processing on supported platforms. |
| DTMF | Dual-tone multi-frequency signaling; may be in-band, RTP telephone-event, or signaling-based. |
| ICE | Interactive Connectivity Establishment for candidate-based NAT traversal. |
| MTP | Media Termination Point; a media resource with specific call-control and media capabilities. |
| NAPTR | DNS Naming Authority Pointer record used in discovery frameworks. |
| PRACK | Provisional response acknowledgment for reliable provisional responses. |
| RTP | Real-time Transport Protocol for media streams. |
| RTCP | RTP Control Protocol, providing reports and control information. |
| SBC | Session Border Controller. |
| SDP | Session Description Protocol; describes session/media parameters and offer/answer negotiation. |
| SIP | Session Initiation Protocol for establishing, modifying and terminating sessions. |
| SRTP | Secure RTP, protecting media packets when negotiated and configured. |
| SRV | DNS service-location record. |
| TLS | Transport Layer Security; SIP TLS protects signaling on a given hop, not RTP automatically. |
| URI | Uniform Resource Identifier, including SIP/SIPS and tel URI forms. |
